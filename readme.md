Правила гри(дії комп'ютера та гравця):
1)Завантажується словник, з якого гра на старті обере випадково одне слово, також обирається рандомне число від 3 до 7 на кількість спроб вгадання цього слова
2)Гравець вводить своє слово, воно перевіряється на довжину (вона повинна співпадати з довжиною вигаданого слова) і на наявність цього слова в самому словнику
3)Комп'ютер порівнює два слова між собою та формує для кожної позиції результат: літеру було вгадано точно, літеру було вгадано частково, літеру не було вгадано. Далі результат зберігається та перевіряється на умову завершення (або слово було вгадано повністю, або закінчилися спроби).


Умови перемоги,поразки:
1)Перемога: гравець вгадав усі літери слова та вклався у ліміт спроб
2)Поразка: слово не було повністю розкрито та закінчилися спроби


"Поза скоупом":
1)Система збереження минулих результатів та їх статистика
2)Мультиплеер та змагання між гравцями
3)Окремий інтерфейс гри (лише робота з консоллю)
4)Додаткові режими складності


Модульний дизайн:
1)SRP: управління словником, визначення ліміту спроб, перевірка коректності введеного слова (правила гри),ігрове поле та стан, введення та виведення (прогрес, повідомлення про помилки), контролер гри (запуск раунду, запит слова, перевірка правил, оновлення стану поля)
2)Інтерфейси абстракції: 
LetterStatus (exact,partial,not_guessed)

GameStatus (in_progress, won,lost)

GuessResult (буде містити введене слово та список статусів від LetterStatus до кожної літери)

WordDictionary(управління словником):
	String getRandomWord(): обирає та повертає випадкове слово зі словника на старті гри
	boolean contains(String word): перевіряє, чи існує введене гравцем слово у словнику

AttemptLimit (визначення ліміту спроб):
	int getMaxAttempts(): генерує та повертає допустиму кількість спроб

GameRules(правила порівняння слів):
	boolean isValidLength(String guess, String secretWord): перевіряє, чи збігається довжина спроби з довжиною загаданого слова
  	GuessResult evaluateGuess(String secretWord, String guess): порівнює спробу із загаданим словом посимвольно та формує GuessResult зі статусами для кожної літери
 	boolean isWordGuessed(GuessResult result): перевіряє, чи всі літери у результаті мають статус exact

GameBoard(ігрове поле та стан раунду):
	void initialize(String secretWord, int maxAttempts): задає загадане слово та ліміт спроб на початку гри
	void addAttempt(GuessResult result): зберігає результат спроби та оновлює статус гри (won,lost,in_progress)
  	List<GuessResult> getAttempts(): повертає історію всіх зроблених спроб
  	int getRemainingAttempts(): повертає кількість спроб, що залишилися
  	GameStatus getStatus(): повертає поточний стан партії
Player (джерело ходів гравця):
  String makeGuess(List<GuessResult> history, int wordLength): повертає слово потрібної довжини на основі історії попередніх ходів

GameView(введення/виведення результатів):
  void displayBoard(List<GuessResult> attempts, int remainingAttempts): виводить історію спроб із маркуванням літер та залишок спроб
  void displayError(String message): виводить повідомлення про помилку
  void displayGameResult(GameStatus status, String secretWord): виводить підсумок партії

3)Конкретні класи реалізації:
	а)FileWordDictionary (реалізує WordDictionary): зчитує слова з текстового файлу, перевіряє їх наявність та повертає випадкове слово
	б)RandomAttemptLimit (реалізує AttemptLimit): генерує випадкове ціле число в межах від 3 до 7
	в)StandardWordleRules (реалізує GameRules): перевіряє довжину слова та виконує порівняння літер (спочатку фіксує всі точні збіги, а потім визначає часткові з урахуванням повторень)
	г)DefaultGameBoard (реалізує GameBoard): зберігає список GuessResult, контролює ліміт спроб і переводить GameStatus у won або lost
	д)ConsoleGameView (реалізує GameView): виводить у консоль спроби, маркування статусів літер і повідомлення
	е)ConsoleHumanPlayer (реалізує Player): зчитує слово-спробу людини з консолі
  	є)SimpleAiPlayer (реалізує Player): підбирає слово "кандидат" зі словника, відсіюючи невідповідні варіанти за результатами з поля history





Впровадження залежностей у GameController:
Клас GameController залежить лише від WordDictionary, AttemptLimit, GameRules, GameBoard, Player, GameView. Він не створює об'єкти самостійно через new, а отримує готові екземпляри через конструктор
